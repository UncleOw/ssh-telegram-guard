# 🛡️ SSH Telegram Guard

Комплексное решение для мониторинга безопасности Linux-сервера с мгновенными уведомлениями в Telegram через [официальный Telegram Bot API](https://telegram.org "Telegram Bot API").

## ✨ Возможности
* **Уведомления об успешных входах (PAM):** Мгновенное оповещение при открытии SSH-сессии (имя пользователя, IP-адрес, имя сервера).
* **Защита от брутфорса (Fail2ban):** Автоматическая блокировка IP-адресов при подборе пароля с отчетом в Telegram.
* **Защита от спама при перезагрузке:** Настроенные директивы `norestored` и `actionflush` предотвращают массовую рассылку старых банов и разблокировок при ребуте сервера.
* **Безопасность данных:** Токены хранятся в защищенном файле `/etc/ssh/tg_guard.env` (права `600`).

## 🚀 Быстрая установка

1. **Клонируйте репозиторий на сервер:**
   ```bash
   git clone https://github.com
   cd ssh-telegram-guard
   ```

2. **Настройте секретные ключи:**
   Скопируйте шаблон конфигурации и впишите туда токен от [@BotFather](https://t.me "BotFather Telegram") и ваш ID от [@userinfobot](https://t.me "userinfobot Telegram"):
   ```bash
   cp .env.example .env
   nano .env
   ```

3. **Запустите установщик:**
   ```bash
   chmod +x install.sh
   sudo ./install.sh
   ```

## 🗑️ Удаление

Если вам нужно отключить уведомления и полностью откатить все изменения в системе, запустите деинсталлятор:

```bash
chmod +x uninstall.sh
sudo ./uninstall.sh
```

## ⚙️ Требования
* ОС: Ubuntu / Debian
* Пакеты: `curl`, `fail2ban` (установщик проверит и установит их автоматически).
